#### Field-boundary observation

The DRE digest section concatenates consecutive integer fields (`revision` + `attempt`) without separators. In isolation this produces identical segment bytes for `(rev=1, att=23)` vs `(rev=12, att=3)`. However, the full replay digest also binds entry and task sections (which independently encode revision), so a complete digest collision is prevented by cross-section redundancy. This is documented as an architectural note — not a production defect.
