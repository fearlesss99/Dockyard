- **After HANDOFF_RESERVED before supervisor**: Resume from exact identity; never create a second handoff (crash row 4)
- **Supervisor started but receipt lagging**: Byte-exact replay of phase advance (crash row 5)
- **Worker started but receipt lagging**: Byte-exact replay of phase advance (crash row 6)
- **ACK submitted, handoff behind**: Byte-exact replay of ACKNOWLEDGED (crash row 7)
- **Finalizer metadata frozen, tombstone incomplete**: Resume finalization (crash row 8)

- **FINALIZED byte-exact replay**: Byte-exact replay (crash row 9)

**Result**: All 15 crash rows have unique, deterministic dispositions.
No undefined or ambiguous windows found.
