## First defect and minimal repair

The first run stopped fail-fast because retry attempted to read
`ScheduledDispatchHandoff.canonical_worktree`, a field that does not exist.
The minimal repair reads and validates the durable `AdmissionPlanReservation`
instead, including task/revision/attempt/dispatch/receipt/digest identity, and
uses its canonical worktree. The same retry path also now supplies the existing
workflow clock adapter required by `WorkflowOrchestrator`.

## Verified execution

2. the exact durable admission plan and finalized handoff are re-read;
3. the real ApprovalGate authorizes attempt 2;

The attempt-limit case proved that failed attempt 3 rejects attempt 4 with the
typed `RETRY_CAS_CONFLICT` result and leaves the event history unchanged.
