## 4. 两个 JSON schema 的生产代码入口

### 4.1 `mad.agents/v1`（Interface #2）

生产入口 `src/mad/cli.py`（`main` → `agents` 分支，`--format json` 路径）：

```python
output = {
    "schema_version": "mad.agents/v1",
    "agents": [agent_to_public_dict(p) for p in profiles],
}
print(json.dumps(output, ensure_ascii=False))
```

- 序列化函数 `agent_to_public_dict` 位于 `src/mad/models.py`，只输出
  `AGENT_PUBLIC_FIELDS` 白名单（id/name/adapter/model/enabled/default_report/
  timeout_seconds/context_budget），排除 `executable`、`extra_args`、`role`。
- 根对象为 object，`schema_version` 固定为 `"mad.agents/v1"`，含 `agents` array。

### 4.2 `mad.run-result/v1`（Interface #4）

生产入口 `RunResult.to_dict()` 位于 `src/mad/models.py`：

```python
def to_dict(self) -> dict[str, Any]:
    data = asdict(self)
    data["schema_version"] = "mad.run-result/v1"
    data["archive_path"] = str(self.archive_path)
    return data
```

- `mad deliberate --format json`（`src/mad/cli.py`）输出该对象。
- `mad resume --format json`（`src/mad/cli.py`）输出兼容对象。
- AgentDesk `mad_gateway.py` 常量 `MAD_RUN_RESULT_SCHEMA = "mad.run-result/v1"`
  与之精确一致；`_validate_mad_output` 严格校验 `schema_version` 与消费字段，
  缺失或错误时 fail-closed（`GatewaySchemaVersionError`）。

## 6. stdout / stderr 边界

- 对 `mad agents --format json`、`mad deliberate --format json`、
  `mad resume --format json`：**stdout 只含单个 JSON 对象**（`json.dumps(...)` 单次
  `print`，无 Markdown、无日志、无前后附加文本）。
- `initialize()`、`load_agents()`、`preflight` 不向 stdout 写任何内容。
- 进度、预检信息、方案预览、警告、档案路径全部进入 **stderr**：
  `progress=lambda message: print(message, file=sys.stderr, flush=True)`，
  `print(..., file=sys.stderr)`。
- 非 JSON 格式（TSV/Markdown）与 JSON 格式边界清晰（`if args.format == "json"`）。
